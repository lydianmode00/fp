UT 0

Introducción al Desarrollo Web en Entorno Servidor

En esta unidad nos prepararemos para el estudio y el trabajo. Haremos alguna revisión de conceptos que tenemos que tener claros y pondremos a punto nuestro entorno de trabajo.

Asumiremos que todos los estudiantes tienen conocimientos básicos de programación y están familiarizados con los conceptos fundamentales de los sistemas informáticos. Haremos simplemente una revisión de los conceptos más importantes.

01. HTML

HTML es un lenguaje de marcado que deberíamos tener muy claro a estas alturas. Si hubiera algún concepto que no recordamos con exactitud, podemos revisar cualquiera de las siguientes dos documentaciones:

  • Documentación de HTML en MDN es la documentación más completa y actualizada de HTML. Es la recomendada para programadores de alto nivel.
  • Documentación de HTML en W3Schools es una excelente recurso para principiantes. Si tenéis problemas para recordar los conceptos básicos deberíais empezar por aquí y recordar lo necesario. Si este es vuestro caso, deberíais poner un empeño especial en poneros al día antes de que sea tarde.

02. CSS

CSS es el lenguaje de estilo por defecto para CSS. Aunque es cierto que podemos usar frameworks como Bootstrap, Tailwind o Foundation, es importante entender los conceptos básicos de CSS para poder utilizarlos de manera efectiva. Los enlaces a la documentación oficial de CSS son:

  • Documentación de CSS en MDN es la documentación más completa y actualizada de CSS. Es la recomendada para programadores de alto nivel.
  • Documentación de CSS en W3Schools es una excelente recurso para principiantes. Si tenéis problemas para recordar los conceptos básicos deberíais empezar por aquí y recordar lo necesario. Si este es vuestro caso, deberíais poner un empeño especial en poneros al día antes de que sea tarde.

03. Python

Python es un lenguaje de programación interpretado de alto nivel. Nosotros lo utilizaremos para el desarrollo de aplicaciones web en el entorno servidor a través del framework Django. Aquí tenemos los enlaces a la documentación de W3Schools y de Django:

  • Documentación de Python en W3Schools: Para dudas sobre el lenguaje
  • Documentación de Django: Para dudas sobre el framework

04. JSON

JSON es un formato de intercambio de datos ligero. Es ampliamente utilizado en aplicaciones web para el envío y recepción de datos entre el cliente y el servidor. Los enlaces a la documentación oficial de JSON son:

  • Documentación de JSON en MDN es la documentación más completa y actualizada de JSON.
  • Documentación de JSON en W3Schools siendo JSON un formato simple de utilizar, ambas documentaciones son útiles para diferentes niveles de experiencia.

05. Git y GitHub

Git es un sistema de control de versiones distribuido. GitHub es una plataforma de hosting para proyectos Git. Antes de comenzar a trabajar con Git y GitHub, es importante entender los conceptos básicos de control de versiones y cómo utilizar estas herramientas para gestionar tu código de forma eficiente.

  • Proyecto: Conjunto de archivos y directorios que representan un trabajo de desarrollo.
  • Repositorio: Un proyecto que está siendo gestionado por Git. Contiene todos los archivos del proyecto y el historial de cambios.
  • Commit: Una instantánea del estado de los archivos en un momento dado. Cada commit tiene un identificador único y un mensaje descriptivo.
  • Branch: Una línea de desarrollo independiente dentro de un repositorio. Permite trabajar en nuevas características o correcciones de errores sin afectar la rama principal (main o master). Normalmente usaremos staging y development como ramas paralelas.
  • Merge: El proceso de combinar cambios desde una rama a otra. Se utiliza para integrar nuevas características o correcciones de errores en la rama principal. Nosotros haremos merges desde development a staging por cada tarea completada y desde staging a main al final de cada unidad.
  • Local: El espacio donde se almacenan los commits antes de ser enviados al repositorio remoto.
  • Remote: El repositorio alojado en un servidor remoto, como GitHub. Permite la colaboración entre varios desarrolladores y el acceso a los cambios desde diferentes ubicaciones. Subo cambios haciendo push a la rama remota, y los descargo haciendo pull.
