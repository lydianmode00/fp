Presentación del módulo

UT 0

Fundamentos del
Mundo Web

Objetivos de la unidad:

  • Conocer la evolución histórica del mundo web
  • Comprender las necesidades y requerimientos del entorno web
  • Configurar nuestro entorno de desarrollo web

UT 1 - RA 1

Lenguajes de
marcas

Objetivos de la unidad:

  • Conocer los lenguajes de marcas y su aplicación en el desarrollo web
  • Usar lenguaje HTML para la construcción de páginas webs y elementos webs sencillos
  • Usar CSS para la gestión de estilos en páginas web

UT 2 - RA 1

Gestores de Contenido
CMS

Objetivos de la unidad:

  • Identificar requerimentos necesarios
  • Gestionar usuarios y roles
  • Personalizar la apariencia del sitio web
  • Instalar módulos y menús
  • Gestionar mecanismos de seguridad
  • Establecer foros y reglas de acceso
  • Realizar copias de seguridad

UT 3 - RA 2

Gestores de
Aprendizaje

Objetivos de la unidad:

  • Reconocer la estructura del sitio y directorios
  • Adecuar la estética del sitio
  • Crear usuarios y asignar roles
  • Implantar foros y vías de comunicación
  • Importar y exportar contenidos en diferentes formatos
  • Generar informes de acceso y uso
  • Realizar copias de seguridad

UT 4 - RA 3

Gestores de
Archivos

Objetivos de la unidad:

  • Describir diferentes aplicaciones de gestión de archivos
  • Instalar una herramienta gestora de archivos
  • Crear usuarios y asignar permisos
  • Aplicar criterios de indexación
  • Comprobar la seguridad de los archivos

UT 5 - RA 4

Aplicaciones de
Ofimática Web

Objetivos de la unidad:

  • Describir diferentes aplicaciones de ofimática web
  • Instalar una herramienta gestora de archivos
  • Crear usuarios y asignar permisos
  • Aplicar criterios de seguridad
  • Usar aplicaciones de forma colaborativa

UT 6 - RA 5

Aplicaciones Web
Generales

Objetivos de la unidad:

  • Describir diferentes aplicaciones de uso general
  • Instalar y configurar correos electrónicos
  • Crear usuarios y asignar permisos
  • Instalar aplicaciones web específicas
